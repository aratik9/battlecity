
# ⚔️ Battle City 3D — Tank Wars

A browser-based 3D tank battle game built with HTML, CSS, JavaScript, and Three.js.

## 🎮 Features

- 3D tank models with tracks, wheels, turrets, and cannons
- 3D battlefield with grass, brick walls, and steel barriers
- Perspective camera, lighting, and real-time shadows
- Enemy tanks with basic AI
- Shooting and collision detection
- Score, lives, and level progression
- Boss tanks every third level
- Mobile-friendly touch controls
- Keyboard controls for desktop

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- Three.js

## 📁 Project Structure

```text
Battle-City-3D/

## 🚀 How to Run

1. Download or clone this project.
2. Open the project folder.
3. Make sure you have an internet connection.
4. Open `index.html` in a modern web browser.
5. Click **START GAME** to begin playing.

Three.js is loaded from a CDN, so an internet connection is required.

## 🕹️ Controls

### Desktop

| Action | Control |
|---|---|
| Move up | W / ↑ |
| Move down | S / ↓ |
| Move left | A / ← |
| Move right | D / → |
| Shoot | Space |
| Restart | R |

### Mobile

- Use the directional buttons to move your tank.
- Press and hold **FIRE** to shoot.
- Tap **START GAME** to begin or restart.

## 🏆 Gameplay

- Destroy enemy tanks to earn points.
- Standard enemies award 100 points.
- Boss tanks award 500 points.
- Survive to advance to the next level.
- Boss levels appear every three levels.
- Protect your base from enemy projectiles.

## ⚙️ Requirements

- A modern browser with WebGL support
- Internet connection to load Three.js
- No build tools or package installation required

## 🔧 Customization

You can edit `index.html` to customize:

- Tank colors and models
- Enemy speed and difficulty
- Battlefield size
- Wall materials
- Camera position
- Lighting and shadows
- Shooting speed and damage

## 📌 Notes

This is a starter 3D tank game project. Some advanced features, such as power-ups, saved high scores, and advanced enemy AI, may require additional development.
